# Changelog

All notable changes are documented here; entries are generated by release-please from Conventional Commits.

## 0.1.0 (unreleased)

### Features

- `classic-diff` engine: SIFT/RANSAC + ECC + optical-flow alignment, tolerant Lab difference, masks
  (`full_frame`, `blue_fixture`, `polygon`), quality gates.
- HTTP API v1: sessions, references (upload / from inspection), asynchronous inspections with long-polling
  and idempotency, crops, operator verdicts with history, manual regions, board verdicts.
- Celery worker, PostgreSQL schema with Alembic migrations, local and S3 storage.
- `pcbis` CLI: API keys, migrations, COCO dataset export with precision/recall, OpenAPI export, bench.
- Docker image, dev and production compose (Caddy TLS, backups), CI with lint, mypy, tests, contract,
  e2e smoke, security scans, releases to GHCR.
